Text Formatting Examples

This is a standard paragraph (<p>) element. It contains text that automatically wraps to the next line when it reaches the edge of the screen.
By using the <br> tag, we forced this text to start on a brand-new line within the same paragraph.

Here is how we can style text inline:

  • Using the strong tag for heavy importance.
  • Using the bold tag for visual bolding without extra importance.
  • Using the emphasized tag for stressed text (renders as italic).
  • Using the italic tag for purely stylistic italicized text.
  • Using the inserted tag for content added to a document (renders as underlined).
  • Using the underline tag for purely visual underlining without semantic meaning.
  • Using the deleted tag for content removed from a document (renders as strikethrough).
  • Using the strikethrough tag for content that is no longer accurate or relevant.
  • Using the mark tag to highlight text for reference (renders with a yellow background).
  • Using the small tag for fine print, side-comments, or legal disclaimers.
  • Using the quote tag for short, inline quotations (browsers automatically add quote marks).
